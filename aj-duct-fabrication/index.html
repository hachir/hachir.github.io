From dimensions to DXF

  1. Choose a pattern and enter neutral-surface dimensions in inches or millimetres.
  2. Set the sheet size, margin, and part spacing. Add quantities to the job list for a mixed job.
  3. Choose “Preview & export job” for the complete job, or export the current pattern directly.
  4. Download DXF exports the current layout. Multiple sheets download as a ZIP with one DXF per sheet and a CSV parts list.
  5. Import the DXF in your plasma CAM software using the matching unit. Verify a known dimension, then set kerf, lead-ins, and cut order.

CUT contains cutting contours. BEND is an optional reference layer; do not cut it. DXF does not contain G-code or machine settings. Transitions and elbows have no joint allowances unless an explicit allowance field is provided.

Projects are local to this browser. Use JSON backups to move them between devices. Employee accounts and shared cloud sync are not included.
